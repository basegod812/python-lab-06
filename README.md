## Установка и запуск
```bash
python -m pip install -r requirements.txt
python flask_app.py
# В другом терминале:
uvicorn api:app --reload --port 8000
```
Flask: http://127.0.0.1:5000  
FastAPI Swagger: http://127.0.0.1:8000/docs

Пример запроса:
```bash
curl http://127.0.0.1:8000/api/hello
```
WebSocket: подключиться к `ws://127.0.0.1:8000/ws` из двух клиентов; сообщения рассылаются всем участникам в памяти процесса.
